# Memorip
나만의 장소 저장 및 공유 서비스

## 주요 기능
:one: **원하는 장소 사진들을 한눈에**
  
사용자가 원하는 장소를 쉽게 찾을 수 있도록 검색과 필터링 기능을 제공합니다.
위치 필터는 원하는 세부 항목을 점점 쌓아가는 방식입니다.

:two: **간편한 앱 사용**

기존 앱들의 UI와 달리 텍스트를 최소화하여 간단한 인터랙션으로 동작합니다.

:three: **취향에 맞게 가져와 사용하는 장소 경험 공유 시스템**

익명 공유를 통해 개인정보 노출 부담 없이 순수하게 장소에 대한 경험을 공유할 수 있습니다.
